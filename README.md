# Robô de Integração SAP Business One

## Sobre o projeto

Aplicação desenvolvida em C# com o objetivo de automatizar a leitura e o processamento de arquivos XML de notas fiscais, integrando-se ao SAP Business One por meio da Service Layer.

O projeto tem como foco o aprendizado prático de C#, integração via API REST e automação de processos no ecossistema SAP Business One.

## Funcionalidades

- Leitura de arquivos XML de uma pasta configurada.
- Extração e validação dos dados da nota fiscal.
- Integração com a Service Layer do SAP Business One.
- Criação de documentos de saída no SAP.
- Tratamento de erros e registro de logs.
- Controle de arquivos processados para reduzir o risco de duplicidade.

## Tecnologias utilizadas

- C#
- .NET
- SAP Business One Service Layer
- API REST / HTTP
- XML
- Git e GitHub

## Objetivo de aprendizado

Desenvolver conhecimentos práticos em programação C#, integração de sistemas, consumo de APIs REST e automação de processos empresariais utilizando o SAP Business One.

## Status do projeto

Em desenvolvimento.

As funcionalidades serão implementadas gradualmente, com foco em boas práticas de programação, organização do código e confiabilidade do processamento.

## Observação

O projeto será testado em ambiente de homologação. A utilização em produção exige validação das regras de negócio e dos requisitos fiscais aplicáveis.
